Для запуска:

Создайте в корне проекта .env и заполните его, пример в example.env

Убедитесь, что на вашем компьютере установлены `docker`, `docker compose` и утилита `make`.

Для запуска проекта в docker:

make build

make up

make base_commands

make logs - для проверки логов

После запуска проект будет доступен по адрессу http://127.0.0.1/
